# Information Agent — 問題追蹤

## 已辨識問題

### P1 — 股價資料不足（29 筆）
- FinMind 僅回傳 30 筆最新股價資料，無法計算 SMA(60) 與 SMA(200)
- 影響: 缺少中長期均線趨勢判斷
- 緩解: 使用 SMA(20) 與價格行為分析替代

### P2 — DCF 估值偏差
- 採用 2026Q1 單季 FCFF (NT$+3.58 億) 進行 DCF 計算
- TTM FCFF 為 -NT$217 億（因大規模資本支出）
- 影響: DCF 結果 (NT$5.18) 偏低且代表性不足
- 建議: 須以正常化 FCFF 或長期平均估算

### P3 — PEG 腳本共享欄位問題
- `valuation.py` 中 `growth_rate` 與 `eps_growth_rate` 共用同一萃取欄位
- DCF 需 decimal (0.15 代表 15%)，PEG 需 whole number (15 代表 15%)
- 影響: 腳本直接執行時 PEG 計算錯誤 (841.2 vs 正確 8.41)
- 緩解: 手動計算 PEG = PE 126.18 / 15% = 8.41

### P4 — 還原股價缺失
- FinMind 還原股價需贊助方案
- 影響: 無法計算完整技術指標的股利調整版本

### P5 — PEG 獲利成長率採用 15% 之保守假設
- 近季 EPS 成長動能強勁 (QoQ +41%, YoY +16,400%)
- 但保守採用 15% 年成長率，可能低估實際成長
- 若採用 25% 成長率，PEG = 126.18/25 = 5.05（仍為高估）
