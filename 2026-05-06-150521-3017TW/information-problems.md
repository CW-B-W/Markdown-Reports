# 資訊層問題記錄 — 3017 奇鋐科技

## 執行問題

### 1. financial_metrics.py 腳本直接執行失敗
- **問題**: `uv run python3 financial_metrics.py analyze 3017 2026-05-06` 回傳空值
- **原因**: 腳本內部呼叫 `finmind_client.py` 與 `yfinance_client.py` 但 API 認證/環境未就緒
- **技術指標**: `price_data.current = 0`, `sma20 = null`, `rsi14 = null`
- **解決方式**: 改用 `compute --input-file` 模式，從 data-report.md 提取 OHLCV 數據傳入

### 2. OHLCV 數據提取遺漏最後一筆
- **問題**: 首次提取只獲得 18 筆 OHLCV (缺少 2026-05-06 跌停日)
- **原因**: data-report.md 中 5/6 的行有 `**` 粗體標記，regex 未匹配
- **解決方式**: 在提取前先移除 `**` 標記，成功提取 20 筆完整數據

### 3. 月營收數據僅到 2025-08
- **問題**: monthly_revenue 表格只涵蓋 2024-05 ~ 2025-08
- **影響**: 無法精確計算 2026 年逐月營收趨勢
- **補救**: 從 CNYES 新聞取得 2026-04 營收 156.31億，計算年增率 71.6%

### 4. 股數不一致
- **問題**: `股本/NT$10` 推導 335M 股 vs `市值/股價` 推導 392M 股
- **原因**: 每股淨值 (150.87) 用 335M 股計算 vs 市值用不同股數
- **處理**: 使用市值推導股數 (392M) 進行估值計算

### 5. 同業比較資料缺失
- **問題**: data-report 未包含雙鴻 (3324)、建準 (2421) 等競爭對手數據
- **影響**: 無法進行相對估值比較 (PE/PB 同業對照)
- **狀態**: 列為資料缺口，於報告中標記

### 6. SMA60 / MACD 無法計算
- **問題**: 僅 20 個交易日數據 (< 60 天)
- **影響**: SMA60、MACD (需26期EMA) 無法計算
- **狀態**: 列為資料缺口

### 7. DCF 估值腳本 PEG 計算單位誤差
- **問題**: valuation.py 的 PEG 函數將 0.15 (15%) 視為整數 0.15 而非 15，導致 PEG=331.87
- **處理**: 手動計算 PEG = 49.78/25 = 1.99 (以 25% EPS 成長率)
- **影響**: 報告中使用手動計算值
