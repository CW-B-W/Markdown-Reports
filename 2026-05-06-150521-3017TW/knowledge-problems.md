# 3017 奇鋐 — @knowledge 問題報告

## 問題 1 — 專家定義缺失 (4/15)

**嚴重度**: 中等  
**描述**: 使用者要求召喚 15 位指定專家，但專家 JSON 定義檔僅收錄其中 11 位。缺失：Terry Smith、Ray Dalio、George Soros、Jim Simons。

**處理**: 以風格相近的 4 位可用專家替代（Ackman、Damodaran、Jhunjhunwala、Taleb）。已於報告中明確標示替代關係。

**建議**: 擴充 experts/ 目錄的 JSON 定義檔，新增缺失專家。

## 問題 2 — Michael Burry 判決格式邊界案例

**嚴重度**: 低  
**描述**: Michael Burry 的原始判決以 `{"verdict": "bearish", ...}` 格式回傳（verdict 為直接字串而非巢狀物件），導致信號提取的正則表達式初次無法匹配。

**處理**: 討論輪結果正確解析，最終以討論輪信號為準。

## 問題 3 — Bill Ackman 討論輪信號解析失敗

**嚴重度**: 低  
**描述**: Ackman 的討論輪回傳內容格式特殊，信號提取函數回傳 "?"。原始判決（看空, 85）可正常解析。

**處理**: 以原始判決為最終信號（看空, 85）。不影響共識結論。

---

## 問題 4 — 批次執行輸出混淆（rtk wc -c）

**嚴重度**: 低（已解決）  
**描述**: STEP 3 第一批次使用 `rtk wc -c` 檢查檔案大小，回傳 0 bytes。實際檔案存在且有內容（buffett 7.0K、graham 7.5K、burry 6.2K）。

**原因**: `rtk` 為非標準命令，其行為與標準 `wc` 不同。

**處理**: 改用 `stat -c%s` 驗證檔案大小。

## 問題 5 — 國際宏觀數據缺失

**嚴重度**: 中等  
**描述**: 缺乏美國 S&P 500、NASDAQ、10 年期美債殖利率等關鍵國際宏觀數據。FinMind API 回傳空值。影響 Druckenmiller、Damodaran 等宏觀導向專家的全面性分析。

**處理**: 已於報告的方法論筆記中標示此限制。專家仍可基於現有數據進行分析，但宏觀層面判斷力受限。

**建議**: @insight agent 可透過 Web Search 補足此數據後做出最終建議。
