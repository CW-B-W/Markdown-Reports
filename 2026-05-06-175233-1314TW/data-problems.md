# 數據問題報告 — 1314.TW (中石化)

## FinMind API 資料缺口

| 缺失數據 | 原因 | 影響 |
|---------|------|------|
| **美股價格 (S&P500, Nasdaq)** | FinMind/USStockPrice 返回空陣列。可能原因：API 需要贊助方案或缺少價格參數（使用 us_stock {symbol} {date}，但可能需指定 date range） | 無法直接取得美股收盤價作為國際對比 |
| **美債10Y殖利率** | FinMind/GovernmentBondsYield 返回空陣列。可能原因：名稱不完全匹配或需要贊助方案 | 無法取得美債利率 |
| **原油價格 (WTI)** | FinMind/CrudeOilPrices 返回空陣列 | 無法取得油價數據 |
| **還原股價 (Adjusted)** | FinMind stock_adj 需 Sponsor 訂閱方案 | 無法取得除權息調整後股價 |

## 數據注意事項

1. **PE = 0.00**: 因近4季EPS為負值(-0.78)，FinMind PER表回傳PE=0。這不代表本益比為0，而是EPS為負無法計算本益比。
2. **殖利率 = 0.00%**: 公司連年虧損，已連續3年未發放現金股利。
3. **股價資料**: 2026-04-08 暫停交易（重大訊息公布），當日開高低收均為0，成交量為0。
4. **外資持股變化**: 2/24至3/23外資持股從11.97%降至8.65%，單月減少約1.25億股，但 FinMind 外資持股資料顯示減少幅度一致，數據合理。
5. **最新財報**: 2026年Q1財報尚未公布（預計5月公告）。

## 建議後續獲取

如果需要遺失的數據，可考慮：
- 使用 playwright-cli 或 webfetch 從公開網站抓取美股/美債/油價
- 使用 yfinance stock 命令補足股價數據
