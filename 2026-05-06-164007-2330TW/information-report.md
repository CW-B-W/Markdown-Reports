## 附錄: 運算方法說明

| 指標 | 公式/來源 |
|:----|:---------|
| SMA20 | 最近 20 個交易日收盤價平均數 |
| RSI-14 | 14 日相對強弱指標: 100 - (100/(1+平均漲幅/平均跌幅)) |
| MACD | EMA12 - EMA26 (指數移動平均) |
| Graham Number | √(22.5 × EPS × BVPS) |
| DCF | 2-stage model: 5年現金流折現 + 終端價值 (g=2.5%, r=10%) |
| NCAV | (流動資產 - 總負債) / 流通股數 |
| Owner Earnings | (淨利 + 折舊 - 資本支出) / 流通股數 |
| PEG | P/E ÷ EPS 年增率 (%) |
| EV/EBITDA | (市值 + 總負債 - 現金) / (EBIT + 折舊攤銷) |
| ROE | TTM 淨利 / 股東權益 |
| ROA | TTM 淨利 / 總資產 |
