## 一、由上層傳遞之未解決問題

### 1. 專家討論輪次 (STEP 4) 跳過 — 🟡 中等
- **問題:** Knowledge Agent 因 token 限制風險策略性跳過 STEP 4（跨專家辯論輪次）
- **影響:** 專家共識僅為獨立裁決的加權平均，未經交叉壓力測試。多方（Lynch/Druckenmiller）的 PEG 論點未與空方（Graham/Pabrai）的 DCF 論點正面交鋒
- **殘留風險:** 共識深度不足。若辯論輪次執行，看空方可能被 PEG 論點說服（或反之），共識分數可能顯著偏移
- **建議:** 未來以較高 token 限制單獨執行討論輪次

### 2. 5/15 專家裁決遭 Token 截斷 — 🔴 嚴重
- **問題:** DeepSeek API max_tokens=2048 導致 Ackman、Bearish Advocate、Damodaran、Burry、Jhunjhunwala 回應不完整
- **影響:** 移除截斷專家後共識從 −0.14 翻轉為 +0.07。共識方向對截斷高度敏感，本質上無法確定
- **補救:** Knowledge Agent 已下調截斷專家信心度並量化不確定性區間
- **殘留風險:** 即使有補救，真實共識仍不確定。Ackman (35) 和 Bearish (50) 的信號可靠度僅 40–70%
- **建議:** 將 max_tokens 提高至 4096 或以上

### 3. 專家替代 (Dalio/Soros/Simons → Damodaran/Jhunjhunwala/Taleb)
- **問題:** 原始指示中的 3 位宏觀/量化專家無定義檔
- **影響:** 面板缺乏純宏觀視角。Damodaran（估值）和 Taleb（風險）雖有價值但非真正替代
- **殘留風險:** 面板對總體經濟、貨幣政策、資金流向的分析深度不足

## 二、Insight 層級之新發現問題

### 4. Capex 正常化 DCF 仍未達市價 — 🔴 重要發現
- **發現:** 即使將 Capex 從峰值 NT$1,738B 降至最低維護級 NT$800B，DCF 最高僅 NT$196.31，仍低於市價 22.1%
- **含義:** 以任何傳統 DCF 框架，2317 在 NT$252 都是高估的。買進 2317 等同於以 PEG/成長框架為主要決策依據
- **Insight 處置:** 此發現構成 HOLD 裁決的核心論據之一，寫入報告第二節「估值框架」

### 5. TAIEX ATH 對 12 個月回報的量化不確定性
- **問題:** FinMind TAIEX API 回傳數據有限，無法進行「歷史新高後 n 個月報酬」的量化回測
- **Knowledge 處置:** 以定性判斷調整機率（保守 30%→40%，樂觀 25%→20%）
- **殘留風險:** 調整幅度為定性判斷，未使用實證模型校準。實際影響可能更大或更小

### 6. 財務報表數據口徑不一致 — 🟢 已記錄
- **問題:** 數據報告中的年度營收（2.0–2.6 兆 TWD）與資訊報告中的營收（6.0–8.1 兆 TWD）存在數量級差異
- **原因:** FinMind API 可能回傳非合併報表數據，而資訊報告以合併口徑自行計算
- **Insight 評估:** 資訊層已自行修正，不影響最終裁決品質

### 7. 外資買盤持續性無法驗證
- **問題:** 三日外資買超 22.2 萬張為極端值，但無足夠歷史數據判斷此規模買盤的後續走勢
- **殘留風險:** 若外資買盤為短期戰術性配置，反手賣出時將觸發劇烈回調
- **Insight 處置:** 將「外資買盤逆轉」列為 🟡 中等風險因子，並建議以外資反手賣超首日為出場訊號

## 三、方法論層級之系統性限制

### 8. 多層報告間之不一致性風險
- **問題:** Data → Information → Knowledge → Insight 各層獨立運作，各層可能對同一數據有不同解讀
- **本次案例:** Data 層財務報表口徑問題在 Information 層被修正，Knowledge 層使用修正後數據。鏈條運作正常
- **殘留風險:** 若某層修正未被下層識別，可能導致連鎖錯誤

### 9. 估值結果對假設的高度敏感性
- **DCF 對 Capex 假設敏感:** Capex 從 NT$1,738B 降至 NT$1,200B，DCF 從 NT$71 升至 NT$143（+101%）
- **PEG 對成長率假設敏感:** 成長率從 23.5% 降至 15%，PEG 從 0.79 升至 1.24
- **含義:** 估值結論脆弱。小幅假設變動可顯著改變裁決方向
