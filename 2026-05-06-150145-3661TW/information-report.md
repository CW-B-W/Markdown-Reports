### 毛利率 vs 營收 — 關鍵觀察

```
營收趨勢:  📉 10,485M → 9,144M → 6,570M → 4,727M  (持續衰退)
毛利率趨勢: 📈 23.2% → 20.6% → 28.0% → 42.3%  (大幅改善)
```

營收與毛利率呈 **反向走勢**，這在設計服務業中典型代表：
- 低毛利量產收入減少 → 營收下降
- 高毛利 NRE/設計收入佔比提升 → 毛利率上升
- 若新專案進入量產 → 毛利率可能再度回落但營收將暴增
