## 四、方法論限制

1. **專家模擬為 AI 生成**：15 位「傳奇投資人」為 DeepSeek API 根據 persona JSON 定義模擬，非真實投資人觀點
2. **無市場微觀結構資料**：未包含委託簿、大單流向、選擇權 Greeks 等
3. **靜態資料快照**：所有分析基於 2026-05-06 收盤資料，市場在報告撰寫期間已可能變動
4. **討論輪可能群體偏誤**：同儕審查機制可能強化主流觀點（群體思維），即使中立派也可能受同儕壓力影響
