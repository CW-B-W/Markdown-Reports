# Information Agent 問題記錄 — 4966.TWO

## 執行日期
2026-05-06

## 問題清單

### P1. yfinance 不可用
- **影響**: financial_metrics.py 腳本的 fundamental 資料提取失敗 (P/E, P/B, 市值等來自 yfinance 的欄位回傳 null)
- **緩解**: 所有 fundamental 數據已由 FinMind API 補齊，在資訊報告中已完整呈現
- **建議**: 若需自動化驗證，請安裝 `pip install yfinance`

### P2. MACD 無法計算
- **影響**: 數據報告僅提供最近21個交易日完整股價資料，MACD 需要至少26個交易日
- **緩解**: 資訊報告已標示 MACD 為缺漏項目，並以布林通道、RSI、SMA 替代分析

### P3. PEG 比率公式差異
- **影響**: valuation.py 腳本將 growth_rate (0.05 = 5%) 直接用作除數，產出 PEG 354.6
- **校正**: 資訊報告中已手動校正為 P/E ÷ 5 = 3.55，並備註說明計算方式
- **建議**: valuation.py 需修正 PEG 計算邏輯，應將成長率轉換為百分比後再計算

### P4. FinMind 美國數據缺口
- **影響**: S&P 500 指數及美債殖利率 API 回傳空陣列
- **影響程度**: 低 — 譜瑞-KY 為台灣上櫃公司，美國總經數據為參考性而非必要

### P5. 股價數據點不足 (120日)
- **影響**: 數據報告僅提取30個交易日的完整 OHLCV
- **緩解**: SMA(5/10/20)、RSI(14)、布林通道已使用可用數據計算
- **建議**: 後續如需 SMA(60) 及完整 MACD，應提取至少60-120個交易日數據
