## 🐂 看多論證 (Bull Case)

### 1. 資產負債表堡壘 — 每股淨現金 NT$892，佔股價 35.4%
- 帳上現金約 NT$1,190億，負債比僅 17.56%，流動比率 4.02，幾乎零銀行借款
- 扣除現金後，實質買進成本僅 NT$1,628，對應 TTM EPS NT$157.76 的實質本益比僅 **10.3倍**
- 巴菲特、蒙格、馬克斯等多位專家均視此為最重要的安全邊際
- 極端下檔風險：即使核心業務獲利減半，現金緩衝仍足以吸收衝擊

### 2. 營收復甦確認 — 4月年增 +22.6%，近一年最強
- 2026年4月營收 NT$53.62億，年增率 +22.6%，為2025年4月以來最大增幅
- 2026Q1合計營收 NT$155.44億，年增 +6.6%，營收成長重回正軌
- Q1 2026 EPS NT$46.63，年化約 NT$186.5，大幅超越TTM水準
- 調查機構已上修全年EPS預估至 NT$182–185元，目標價 NT$2,900元

### 3. 估值深度折價 — DCF公允價值 NT$3,483，38%上漲空間
- DCF模型（保守假設3%成長率、10%折現率）得出公允價值 NT$3,483
- FCF殖利率高達 **10.10%**，在全球大型科技股中極為罕見
- EV/EBITDA僅 **6.8倍**，考量零淨負債結構屬於低估
- 情境一（機率35%）：5月營收優於預期 + 外資加速回補 → 目標價 NT$2,800–3,000（+11%至+19%）

### 4. 外資回補趨勢明確 — 持股比 31.3%，仍有空間
- 外資持股自2026年初低點 28.8% 回升至 31.30%
- 距離2024年水準 32–34% 仍有約 3 個百分點回補空間
- 台股全市場外資買超751億，資金動能強勁
- 台指期正價差416點，期貨市場對後市樂觀

### 5. 多項催化劑疊加 — CPO、法說會展望、H2旺季
- CPO光學模組準備送樣，開闢新成長曲線（長期選擇權價值）
- 管理層法說會稱「4-5月動能優於去年同期」確認谷底已過
- 下半年為傳統旺季（7-10月），季節性營收增長有助支撐股價
- 融券餘額僅5張（趨近於零），無顯著空方壓力

## 🐻 看空論證 (Bear Case)

### 1. EPS連續衰退 — TTM EPS NT$157.76，年減 18.7%
- FY2024 EPS NT$194.17 → FY2025 NT$159.41（-17.9%）→ TTM NT$157.76
- 即使排除2025Q2一次性業外損失30.85億，核心獲利仍在收縮
- Q1 2026年化EPS NT$186.5雖優於TTM，但仍低於2024年水準
- 管理層預告4-5月營收「逐月下滑」，短期動能不足

### 2. 毛利率結構性下滑 — 59.1% → 49.4%，護城河侵蝕訊號
- 毛利率自2024Q4高點 59.1% 降至2026Q1 49.4%，累計下滑近10個百分點
- 營業利益率同步從 39.7% 降至 37.4%
- 費雪、巴菲特、達里歐等專家均視此為重大警訊
- 中國競爭對手（舜宇光學、歐菲光）追趕加劇，定價能力受壓
- 智慧型手機鏡頭規格升級趨緩（8P→9P進展有限），ASP成長受限

### 3. 短線技術面弱勢 — RSI 33.7，MACD死亡交叉
- 股價低於SMA20（NT$2,555），形成短線壓力
- RSI(14) = 33.7，接近超賣區但未確認反轉
- MACD柱狀圖連續負值，動能向下
- 自4月高點NT$2,820回落10.6%，量縮整理中
- 若跌破SMA60（NT$2,402）將測試SMA200（NT$2,336），對應約-7%下行

### 4. 葛拉漢數字顯示高估 — NT$2,228 vs 市價 NT$2,520（溢價13%）
- 嚴格價值標準全數未過：PE 15.73 > 15、PB 1.79 > 1.5
- 葛拉漢數字 NT$2,227.77，市價溢價 13.1%，安全邊際為零
- 深度價值投資人（葛拉漢、帕伯萊）無法在此價位進場
- 情境三（機率20%）：失望性賣壓 → 目標價 NT$2,200–2,350（-7%至-13%）

### 5. 風險因素疊加 — 侵權訴訟、Apple集中度、地緣政治
- 侵權訴訟進行中，最壞情況可能涉及賠償或營運限制
- 高度依賴Apple iPhone鏡頭訂單（營收集中度風險）
- 美中關稅戰升溫可能影響供應鏈布局
- 台海地緣政治風險為無法對沖的系統性風險
- 年化波動率高達63.39%（一個月可從2,430→2,820→2,520）

## 🧠 @insight 獨立判斷

### 為何信心度設為 65%（而非專家平均的 ~60%）

1. **專家意見雖分散但方向明確**: 6位看多（信心平均75%）對 2位看空（信心平均50%），看多陣營信心度明顯更高。7位中立並非看空，而是等待催化劑確認。

2. **資產負債表提供罕見的下檔保護**: 每股淨現金NT$892本身就是安全邊際，即使看空的葛拉漢也在低信心度（40%）下承認「高估非極端」。

3. **營收復甦為客觀數據**: 4月營收年增+22.6%是硬數據而非主觀判斷，這降低了猜測成分。

4. **扣分因素**: 毛利率趨勢（59%→49%）與管理層預告5月營收月減，抵銷了部分樂觀理由，因此信心度不設更高。

### 關鍵觀察點（未來一個月）

1. 📅 **5月營收公布** (6月初) — 管理層預告月減，實際幅度為最關鍵變數
2. 🏢 **外資買賣超** — 持股比能否突破32%加速回補至關重要
3. 📊 **SMA20 (NT$2,555)** — 站回則短線轉強，確認修正結束
4. 🛡️ **SMA60 (NT$2,402)** — 關鍵支撐，跌破將測試SMA200 (NT$2,336)
5. ⚖️ **侵權訴訟進展** — 若有利空可能引發短期賣壓
6. 📱 **Apple供應鏈消息** — iPhone新機備貨動向直接影響下半年營收預期
