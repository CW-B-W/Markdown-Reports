### 2. Ask-Order 階段輸出問題

第一批（bullish, bearish, buffett）的 `--ask-order` 指令執行時，輸出顯示 "No output"。原因為並行執行時未使用 `--json` 旗標，且輸出可能寫入 stderr 而非 stdout。後續批次加回 `--json` 旗標後正常運作。

**影響**: 無實質影響 — ask-order 結果未用於後續判決（判決階段直接使用完整資訊報告）。

### 3. 判決輸出格式不一致

不同專家返回的 JSON 結構略有差異：
- 部分專家輸出 `{ "signal": "...", "confidence": ..., "reasoning": "..." }`
- 部分專家輸出 `{ "verdict": { "signal": "...", ... } }`
- Burry 輸出的 `reasoning` 為陣列而非字串

**處理**: 在建立討論檔案時統一套用 `{ signal, confidence, reasoning }` 結構，手動解析各專家的實際輸出。

### 4. 討論回合時間較長

每位專家的討論回合（含思考模式）約需 30-90 秒，15位專家共5批次，總耗時約 8-12 分鐘。若需加速，可考慮降低 `thinking.effort` 參數或減少討論回合數。
